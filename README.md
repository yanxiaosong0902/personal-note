# 个人便签

一个用 Python 实现的 macOS 菜单栏应用。保存网址、电话、地址、代码片段和终端命令，之后用关键词找回原文。

这台 Mac 已配置登录后运行快捷键监听器。按 `⌘⇧Y` 即可启动并打开便签，退出便签后仍可用同一快捷键重新启动。

开发时如需手动运行，可先停止快捷键监听器，再在项目目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

应用运行期间菜单栏会显示「便签」。在菜单栏选择「退出」即可结束进程。全局快捷键仅在应用运行期间生效。

- **保存**：先复制文字，按 `⌘⇧Y` 打开窗口，直接按 `⌘V` 保存。输入备注后按回车保存并关闭，或按 `Esc` 跳过备注。重复保存会创建独立记录。
- **手动新增**：点击搜索框右侧的 `+`，填写原文和可选备注后点击「保存」。
- **查找**：打开窗口后直接输入关键词，可匹配原文或备注。搜索框已有文字时，`⌘V` 会正常粘贴搜索词。记录按保存时间倒序，默认选中第一条。
- **取回**：用方向键或鼠标选中记录，按回车复制完整原文，窗口会关闭并返回之前的应用。换行和缩进会原样保留。
- **管理**：右键点击记录，可编辑原文和备注，也可以删除。

记录保存在本机的 `~/Library/Application Support/PersonalNotes/notes.sqlite3`，应用重启后仍可查找。

运行检查：

```sh
.venv/bin/python -m unittest discover -s tests
.venv/bin/python app.py --smoke-test
```

启动检查需要 macOS 图形会话，使用临时数据库。运行前先退出已经启动的个人便签，以免占用快捷键。
